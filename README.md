
## Правила
* 2–6 игроков, у каждого 10 шашек в своём луче; цель — противоположный луч.
  Лучи: 2 игрока — напротив друг друга, 3 — через один, 4 — две пары, 5 и 6 — подряд.
* Ход: шаг на соседнюю свободную клетку **или** цепочка прыжков через соседние шашки (свои/чужие)
  на свободную клетку сразу за ними. Смешивать шаги и прыжки нельзя.
* Партия заканчивается по завершении круга, в котором кто-то собрал все шашки в цели.
  Меньше ходов — победа; равное число ходов — ничья. Нет ходов — пропуск хода.
  Защита от бесконечных партий: лимит кругов (по умолчанию 300), итог `UNFINISHED`.
* Турнир: победа 2 очка, ничья по 1; при `UNFINISHED` побеждает больший `Evaluator.progress`.

## Алгоритмы и паттерны
* Граф и BFS: `Board.reachableByJumps` (очередь `ArrayDeque`, множество посещённых, `LinkedHashMap` родителей
  для `jumpPath`). Исходная клетка считается пустой.
* Strategy — `Bot`/`ScoringBot`/`MoveScorer` (лямбды); Factory method — `Bots.create`;
  Observer — `Game.subscribe`; обобщённый `Standings<T>`, компараторы и Stream API в рейтинге и оценках.
* Воспроизводимость: один `java.util.Random(seed)`, механика сама случайности не использует.
